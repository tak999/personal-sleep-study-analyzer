# Personal Sleep & Study Analyzer

A personal tool for retrieving the owner's Oura data and reviewing relationships between sleep, activity, readiness, work, and study time. It is used only by its owner and is not offered as a service to third parties.

This repository contains public documentation only. Health data, email addresses, and authentication credentials are not published here.
